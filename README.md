# Simple Image Convert

I built this because the current image conversion offerings are more comprehensive than I need.
They're generally excellent tools, but I really just want to convert/compress images that I get from my phone.

The goal of this plugin is to enable very basic image compression without many options.
At the moment (and for the foreseeable future), only WebP is supported as a target format.
It offers good quality to size performance and it's widely compatible.
I may add support for other target formats in the future, but maybe not.

The reason to keep this so small and targeted is to reduce the surface area for bugs and security concerns.
I want this to do a very specific job and be easy to maintain so it's a well functioning plugin for years to come.
